# ✈️ British Airways Data Science Job Simulation

This repository contains my solutions to the **British Airways Data Science Job Simulation** hosted on **Forage**. The simulation focuses on applying data science techniques to solve real-world business challenges within the airline industry.

Through two practical projects, I used **Excel**, **Python**, and **Machine Learning** to develop data-driven solutions that support business decision-making, customer experience, and operational planning.

---

## 📌 Project Overview

The simulation consists of two independent tasks:

### **Task 1: Modeling Lounge Eligibility at Heathrow Terminal 3**

Developed an Excel-based lookup table to estimate passenger lounge eligibility across different flight categories. The solution provides a scalable framework for forecasting lounge demand without relying on detailed passenger or aircraft information.

**Key Skills**

- Microsoft Excel
- Data Analysis
- Lookup Tables
- Business Analytics
- Forecasting
- Airport Operations Planning

📂 **Project Folder:** `Task_1_Lounge_Eligibility`

---

### **Task 2: Predicting Customer Buying Behaviour**

Built a machine learning model to predict whether customers would complete a holiday booking based on their booking behaviour and travel preferences.

The project included exploratory data analysis, feature engineering, model development, hyperparameter tuning using GridSearchCV, and model evaluation with business recommendations.

**Key Skills**

- Python
- Pandas
- NumPy
- Scikit-learn
- Machine Learning
- Predictive Analytics
- Feature Engineering
- Model Evaluation

📂 **Project Folder:** `Task_2_Customer_Buying_Behaviour`
